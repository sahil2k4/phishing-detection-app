# 🚀 About

Phishing websites imitate trusted websites to steal sensitive information like passwords, banking credentials, OTPs, and personal data.

This project uses **Machine Learning** to analyze website URL characteristics and classify URLs as either:

✅ Legitimate Website

❌ Phishing Website

The application provides instant predictions through a clean Flask web interface.

# ⚙️ Installation

Clone Repository

```bash
git clone https://github.com/sahil2k4/phishing-detection-app.git
```

Move into directory

```bash
cd phishing-detection-app
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Application

```bash
python app.py
```

Open Browser

```
http://127.0.0.1:5000
```

---

# 💻 Usage

1. Launch the Flask application.
2. Enter any website URL.
3. Click **Predict**.
4. The model extracts URL features.
5. Prediction is displayed instantly.
